Run SpikeInterface on Windows

A clean, no-conda install using uv. uv installs Python for you and builds the whole environment from a locked file — no Anaconda, no compiler, no PATH wrangling.

⏱ ~10 min first time 🪟 Windows 10 / 11 🧱 No compiler needed 🐍 Python 3.12 (auto)
What you'll need: a Windows PC, an internet connection, and the recording files (PFCM7_d0ephys_Block2.ns2 / .ns5 / .nev). The raw data is not in the repository (the .ns5 is ~176 MB), so you copy it in yourself in Step 3.

Setup — do these once

1

Install uv

Open PowerShell (press ⊞ Win, type PowerShell, Enter) and run:

winget install --id=astral-sh.uv -e

No winget? Use this instead:

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Then close and reopen PowerShell so uv is on your PATH.

2

Get the project

Clone the repository (replace <repo-url> with the actual URL), or copy the project folder onto the PC. Then move into it:

git clone <repo-url> SpikeInterface
cd SpikeInterface

Run every remaining command from inside this folder.

3

Add the recording data

Copy the three data files into the root of the project folder (next to pyproject.toml):

SpikeInterface\ ├─ PFCM7_d0ephys_Block2.ns2 (LFP, 1 kHz) ├─ PFCM7_d0ephys_Block2.ns5 (raw broadband, 30 kHz — ~176 MB) └─ PFCM7_d0ephys_Block2.nev (spike events)

No data yet? You can still install — the menu just won't have a recording to act on.

4

Build the environment

This one command downloads Python 3.12 and every dependency (SpikeInterface, the PySide6 GUIs, the sorters) from the locked file:

uv sync

First run takes ~5–10 minutes (PySide6 is large). Everything installs as prebuilt wheels — no Visual C++ / build tools required. To also get the Jupyter notebooks:

uv sync --extra notebooks
5

Verify it works

recommended

Quick smoke test — checks the libraries load and the data reads:

uv run python scripts\verify_install.py

Success ends with All good — SpikeInterface can read your data. ✓

Run it — every time after

6

Open the menu

Easiest: double-click run.bat in the project folder.

Or from a terminal in the folder:

.\run.bat

Equivalent, without the launcher script:

uv run python SpikeInterface_Menu.py

Run one action directly (skip the menu), e.g. build the HTML report:

.\run.bat report

Data in another folder? Add --data-dir to any command, e.g. .\run.bat report --data-dir C:\path\to\recording.

What's in the menu

exploreQuick LFP + spike figures
sortSpike-sort the broadband
reportBuild & open HTML report
guispikeinterface-gui inspector
tracesScroll raw traces (ephyviewer)
compareAgreement between sorters
verifyEnvironment smoke test

Move with ↑/↓; switch between the Sorter and Actions panes with ←/→ or Tab. Enter runs the highlighted action (or activates the highlighted sorter); the number keys 1–9 jump-run an action. t switches the active sorter, d opens the data-setup help, q quits.

Notes & troubleshooting

Best display: use Windows Terminal (or Windows 10 1903+) so the full-screen menu's shield and box-drawing render correctly. run.bat already sets PYTHONUTF8=1 for you.
“No module named …”? Make sure you ran uv sync in the project folder, and launch scripts with uv run python … (or run.bat) — uv resolves the environment automatically, so there is nothing to “activate.”
Prefer conda? It still works as a fallback: conda env create -f environment.yml then conda activate si_env. The uv path above is the recommended one and needs no conda.
